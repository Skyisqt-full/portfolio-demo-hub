# Demo flow

## Goal

Show the portfolio as a product control room, not as a static resume.

## Main scenario

1. Open the home screen.
2. Filter projects by stack or business task.
3. Open a project card.
4. Review business problem, stack and demo status.
5. Start live preview or read the demo flow.
6. Open code highlights for the selected UI/API area.

## Acceptance criteria

- A client can understand what problem each project solves in less than one minute.
- Every flagship project links to GitHub and has a clear local run path.
- Mocked integrations are marked explicitly.
